# Test Scripts Directory

This directory contains all development, testing, and debugging scripts that were previously scattered in the root directory.

## Categories

### Test Scripts (`test_*.py`)

- **test_aruco_mask.py** - ArUco marker masking tests
- **test_auto_directory_mode.py** - Auto directory processing tests
- **test_detector.py** - Core detector functionality tests
- **test*web*\*.py** - Web server and upload functionality tests
- **test*template*\*.py** - Template creation and management tests
- **test_notification.py** - Notification system tests
- And many more...

### Debug Scripts (`debug_*.py`)

- **debug_content_masking.py** - Content masking debugging
- **debug_web_upload_flow.py** - Web upload flow debugging
- **debug_marker_detection.py** - ArUco marker detection debugging
- **debug_real_photo.py** - Real photo processing debugging
- And others...

### Cleanup Scripts (`cleanup_*.py`)

- **cleanup_automated_masks.py** - Automated mask cleanup utilities
- **cleanup_test_scripts.py** - Test script cleanup utilities

### Scan Test Scripts (`scantest*.py`)

- **scantest.py** - Basic scanning tests
- **scantest2.py** - Advanced scanning tests
- **scantest_backup.py** - Backup scanning tests
- **scantest_simple.py** - Simplified scanning tests

### Check Scripts (`check_*.py`)

- **check_db.py** - Database integrity checks
- **check_image_sizes.py** - Image size analysis

### Development Tools

- **pyinstxtractor.py** - PyInstaller extraction tool
- **detector_decompiled.py** - Decompiled detector analysis
- **Testtest.py** - General testing script

## Usage

These scripts are primarily for development and testing purposes. Most are standalone and can be run individually for specific testing or debugging needs.

**Note**: Some scripts may require specific test data or may be outdated. Review the script content before running.
